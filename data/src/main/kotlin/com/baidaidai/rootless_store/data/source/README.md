# Source Remote Contract

本目录用于处理 Rootless Store 中与 `Source` 相关的本地数据、远端接口和仓储实现。

在对接后端 `Services` 时，请遵循以下约定：

1. Rootless Store 不强制规定默认也不关心必须使用 `V1`、`V2` 或 `V3` 路径。
2. 但是同一个 `Source` 一旦选择了某个版本前缀（例如 `Vn`），该版本必须保持稳定且一致。
3. 不允许出现版本混用的情况，例如：
   - 获取 `source` 元信息使用一个版本；
   - 获取插件列表时又切换到另一个版本。
4. 只要该 `Source` 的服务实现符合 Rootless Store 的 `Services` 远端契约，即可被接入。

示例：

- 可以使用 `/api/v1/...`
- 也可以使用 `/api/v2/...`
- 或者使用 `/api/v3/...`

但必须保证同一个 `Source` 下的接口版本策略一致，避免同一组服务出现不稳定或不可预测的路径行为。
