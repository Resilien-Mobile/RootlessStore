# 环境运行时支持版

Welcome to Rootless Store v0.0.9!

This update focuses on decoupling and managing plugin execution environments. In v0.0.9, the app introduces runtime support for environment packages, adds a dedicated environment management panel within the plugin screen, and refines the overall localized interface for a more structured user experience.

欢迎来到 Rootless Store v0.0.9！

这个版本的重点，在于对插件执行环境的解耦与管理。v0.0.9 引入了环境包运行时支持、在插件页面新增了专门的环境管理面板，并进一步优化了本地化界面，让整体使用体验更具结构化。

---

### What's New in v0.0.9

* **Environment Package Runtime Support**:
    * **Decoupled Execution Environments**: Introduced a new system to manage environment packages, allowing plugins to leverage specific runtimes and toolsets independently.
    * **Runtime Infrastructure**: Added data models and repository support (EnvironmentManifest, Room entities) to handle the lifecycle of these environment-providing packages.
* **New Environment Management Panel**:
    * **Integrated Environment Screen**: Added a new "Environment" tab to the Plugin screen, providing a clear view of all installed runtime environments.
    * **Management Actions**: Users can now view details of installed environments and perform uninstallation tasks directly within the app.
* **UI & Interaction Refinements**:
    * **Secondary Navigation on Plugin Screen**: Introduced a tab-based navigation on the Plugin screen to easily switch between "Plugins" and "Environment".
    * **Localized Tab Labels**: Localized the new navigation labels to maintain a consistent multilingual experience.
* **Environment Lifecycle Improvements**:
    * **Uninstall Flow**: Added a dedicated flow for removing environment packages, ensuring the local environment state stays clean and manageable.

### v0.0.9 更新内容

* **环境包运行时支持**:
    * **解耦的执行环境**: 引入了全新的环境包管理系统，允许插件独立利用特定的运行时环境与工具集。
    * **运行时基础设施**: 新增了数据模型与仓库支持（EnvironmentManifest、Room 实体），用于处理这些提供环境支持的包的完整生命周期。
* **新增环境管理面板**:
    * **集成的环境页面**: 在插件页面中新增了“环境”标签页，提供所有已安装运行时环境的清晰视图。
    * **管理操作**: 用户现在可以在应用内直接查看已安装环境的详情，并执行卸载任务。
* **UI 与交互细节优化**:
    * **插件页面二级导航**: 在插件页面引入了基于标签页的导航，方便在“插件”与“环境”视图之间快速切换。
    * **本地化标签支持**: 对新增的导航标签进行了本地化处理，保持一致的多语言体验。
* **环境生命周期管理完善**:
    * **卸载流程支持**: 新增了专门的环境包卸载流程，确保本地环境状态保持整洁且可管理。

---

### Key Features

* **Separation of Concerns**: By separating environments from core plugins, Rootless Store now offers a more flexible architecture for complex runtime requirements.
* **Centralized Environment Visibility**: The new environment panel makes it easier for users to understand what runtimes are currently available on their device.
* **Unified Plugin & Environment Management**: Managing both plugins and their required environments in one screen improves operational efficiency.
* **Ongoing Localization Integrity**: Key UI navigation elements continue to be brought into the internationalization framework.

### 主要功能

* **关注点分离**: 通过将执行环境与核心插件分离，Rootless Store 现在能为复杂的运行时需求提供更灵活的架构支持。
* **集中的环境可见性**: 新的环境面板让用户能够更容易地了解当前设备上已启用了哪些运行时环境。
* **统一的插件与环境管理**: 在同一个页面内管理插件及其依赖环境，提升了操作效率。
* **持续的本地化演进**: 核心 UI 导航元素持续纳入多语言框架，确保体验的完整性。
