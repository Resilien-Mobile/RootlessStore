# Rootless Store v2.1.0 发布：插件，从此拥有界面

Welcome to Rootless Store v2.1.0!

Rootless Store v2.1.0 is one of the most significant capability upgrades in the 2.x series so far.

With the arrival of plugin WebUI support, plugins are no longer limited to switches, one-tap actions, and plain text output. Supported plugins can now present complete visual interfaces directly inside Rootless Store, turning complex operations into experiences that feel as natural as using an app.

欢迎来到 Rootless Store v2.1.0！

Rootless Store v2.1.0 是目前 2.x 系列中最重要的能力升级之一。

随着插件 WebUI 正式加入，插件不再局限于开关、单次执行和纯文本输出。支持该能力的插件现在可以直接在 Rootless Store 中呈现完整的可视化界面，将复杂操作变成像使用普通 App 一样自然、直观的交互体验。

---

### What's New in v2.1.0

* **Plugin WebUI Is Here**:
    * Supported plugins can now provide their own visual interfaces.
    * Settings, actions, information, and execution results can be presented in a clearer and more approachable way.
    * Users no longer need to understand every command or inspect raw output to use more advanced plugin features.

* **Direct Access from Installed Plugins**:
    * Plugins with WebUI support now display a dedicated entry in their action area.
    * The plugin interface opens directly inside Rootless Store without redirecting users to an external browser.
    * Plugins without a WebUI remain unchanged, keeping the plugin list clean and familiar.

* **Initial KernelSU WebUI Compatibility**:
    * Rootless Store now provides initial compatibility with KernelSU-style plugin interfaces.
    * This opens the door for more existing visual plugin experiences to reach Rootless Store users.
    * Compatibility may vary between plugins in this first release and will continue to expand in future updates.

### v2.1.0 更新内容

* **插件 WebUI 正式登场**:
    * 支持该能力的插件现在可以拥有自己的可视化界面。
    * 设置、操作、信息和执行结果都可以通过更加清晰、易懂的方式呈现。
    * 用户无需理解每一条命令或反复查看原始输出，也能使用更复杂的插件功能。

* **从已安装插件直接进入**:
    * 支持 WebUI 的插件会在操作区域中显示专属入口。
    * 点击后即可直接在 Rootless Store 内打开插件界面，无需跳转到外部浏览器。
    * 不支持 WebUI 的插件不会受到影响，原有插件列表依旧保持简洁。

* **初步兼容 KernelSU WebUI 生态**:
    * Rootless Store 现在开始支持 KernelSU 风格的插件界面。
    * 这为更多已有的可视化插件体验进入 Rootless Store 打开了新的可能。
    * 作为首个支持版本，不同插件的兼容程度可能有所差异，后续版本会继续扩展。
