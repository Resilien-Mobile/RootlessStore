# Code Brick 工作流补完发布版

Welcome to Rootless Store v1.5.1!

This release continues improving Code Brick. Existing bricks can now be adjusted after creation, and users can choose where a brick should run, making reusable scripts more flexible and closer to a complete daily workflow.

欢迎来到 Rootless Store v1.5.1！

这个版本继续补完 Code Brick。现在，已经创建的 Brick 可以再次调整，用户也可以选择脚本的运行环境，让可复用脚本更灵活，更接近完整的日常使用流程。

---

### What's New in v1.5.1

* **Edit Existing Code Bricks**:
    * Code Bricks can now be reopened and modified after creation.
    * Users can update the brick name and script content without deleting and recreating it.

* **Choose Runtime Context**:
    * Code Bricks now support choosing where the script runs.
    * Available options include App Shell, ADB Shell, and Root Shell.

* **More Complete Settings Flow**:
    * The settings button on each Code Brick card is now functional.
    * Users can adjust a saved brick from its card, then confirm the changes directly.

* **Better Code Brick Creation Flow**:
    * New Code Bricks can now be created with a selected runtime context from the beginning.
    * This reduces the need to manage different scripts manually for different execution environments.

### v1.5.1 更新内容

* **支持编辑已有 Code Brick**:
    * Code Brick 创建后，现在可以重新打开并修改。
    * 用户可以直接更新 Brick 名称和脚本内容，不再需要删除后重新创建。

* **支持选择运行环境**:
    * Code Brick 现在可以选择脚本的运行位置。
    * 当前支持 App Shell、ADB Shell 和 Root Shell。

* **设置流程补完**:
    * 每个 Code Brick 卡片上的设置按钮现在已经可用。
    * 用户可以从卡片直接进入设置，调整后确认保存。

* **创建流程更完整**:
    * 新建 Code Brick 时，现在可以一并选择运行环境。
    * 这减少了用户为不同执行环境手动管理多份脚本的负担。
