# 调试签名补丁版

Welcome to Rootless Store v0.0.902!

This is a small release focused on the GitHub build and release pipeline. In v0.0.902, Rootless Store adds static signing support for debug APKs and refines the CI/CD output flow, making distributed test builds more stable and easier to use.

欢迎来到 Rootless Store v0.0.902！

这是一次体量很小的更新，重点放在 GitHub 构建与发布链路上。v0.0.902 为调试 APK 增加了固定签名支持，并顺手整理了 CI/CD 的产物输出方式，让分发出来的测试包更稳定，也更方便使用。

---

### What's New in v0.0.902

* **Static Debug Signing**:
    * Added a dedicated signing config for GitHub-built debug APKs.
    * Makes distributed debug builds more stable and easier to install or update consistently.
* **Release Pipeline Updates**:
    * The release workflow now builds the dedicated signed APK variant.
    * Signing secrets are now applied in the GitHub release flow.
* **Artifact Output Cleanup**:
    * CI and release workflows now collect APK outputs with a broader path rule, making artifact uploads more reliable.

### v0.0.902 更新内容

* **固定调试签名支持**:
    * 为 GitHub 构建出来的调试 APK 增加了专用签名配置。
    * 让分发出去的调试包在安装与后续更新时更稳定、更一致。
* **发布流程调整**:
    * Release 工作流现在会构建专门的签名 APK 变体。
    * GitHub 发布流程中接入了签名所需的 secrets。
* **产物上传整理**:
    * CI 与 Release 工作流统一放宽了 APK 产物收集路径，让上传结果更可靠。
