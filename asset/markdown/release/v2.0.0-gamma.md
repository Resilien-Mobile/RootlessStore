# Rootless Store 2.0 Gamma 发布

Welcome to Rootless Store v2.0.0-gamma!

This Gamma release focuses on refining the Code Brick experience, improving language consistency and fixing several interaction issues.

欢迎来到 Rootless Store v2.0.0-gamma！

本次 Gamma 更新主要聚焦 Code Brick 的使用体验，补齐多语言内容，并修复部分交互问题。

---

### What's New in v2.0.0-gamma

* **Improved Code Brick Language Support**:
    * Remaining text on the Code Brick screen now follows the selected app language.
    * Actions such as creating Code Bricks, binding Quick Settings tiles, and converting Code Bricks into plugins are now displayed more consistently.
    * English, Simplified Chinese, and Traditional Chinese experiences are now more complete.

* **Code Brick Menu Interaction Fixes**:
    * The creation menu now closes correctly after selecting an action.
    * Tapping an empty area of the page will also close the menu.
    * Fixed cases where the menu could remain expanded and obstruct subsequent operations.

### v2.0.0-gamma 更新内容

* **Code Brick 多语言体验补全**:
    * Code Brick 页面中此前残留的文本现在会跟随应用语言显示。
    * 创建 Code Brick、绑定快捷磁贴以及转换为插件等操作的文案更加统一。
    * 进一步补全了英文、简体中文和繁体中文的使用体验。

* **Code Brick 菜单交互修复**:
    * 选择创建方式后，菜单现在会正确收起。
    * 点击页面空白区域也可以关闭菜单。
    * 修复了菜单可能持续展开并影响后续操作的问题。
