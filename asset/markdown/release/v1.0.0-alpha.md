# 私有源与市场链路 Alpha 版

Welcome to Rootless Store v1.0.0-alpha!

This release focuses on the latest progress around private sources, authenticated source registration, market presentation, and installation reliability. Rather than broadening scope, v1.0.0-alpha tightens several key flows that are essential to making Rootless Store usable as a real plugin distribution and runtime platform.

欢迎来到 Rootless Store v1.0.0-alpha！

这个版本主要聚焦于最近一轮围绕私有源、认证式 Source 注册、Market 展示，以及安装稳定性所做的推进。它不是简单地继续堆功能，而是在插件分发与运行平台这条主线上，把几个关键流程进一步收紧和补齐。

---

### What's New in v1.0.0-alpha

* **Private Source Support**:
    * Added authenticated source registration flow for private sources.
    * Source screen can now prompt for authentication when a source requires private access.
    * Access control results are now handled more explicitly during source registration.
* **Source Model Refinement**:
    * Reworked source contracts into clearer source info models.
    * Improved source persistence, mapping, and registration flow to better support authenticated and structured sources.
* **Market Flow Improvements**:
    * Added support for installing environment packages directly from the Market flow.
    * Redesigned Market cards with manifest tags for clearer plugin presentation.
    * Updated Market paging to use a shared manifest collection model.
* **Installation Stability Improvements**:
    * Improved plugin installation robustness by catching manifest detection errors during install.

### v1.0.0-alpha 更新内容

* **私有源支持**:
    * 新增了面向私有源的认证式注册流程。
    * 当某个 Source 需要私有访问时，Source 页面现在会主动弹出认证提示。
    * Source 注册过程中，对访问控制结果的处理也变得更加明确。
* **Source 模型整理**:
    * 将原有的 Source 合约重构为更清晰的 Source 信息模型。
    * 优化了 Source 的持久化、映射与注册流程，使其更适合承载认证源和结构化源。
* **Market 流程增强**:
    * Market 流程现已支持直接安装环境包。
    * 对 Market 卡片进行了重新设计，并加入 manifest 标签，让插件展示更清晰。
    * 更新了 Market 分页所使用的 manifest 收集模型。
* **安装稳定性提升**:
    * 在插件安装过程中补充了 manifest 检测错误处理，提升了安装阶段的稳定性。

---

### Why This Alpha Matters

* Rootless Store is beginning to support not just public plugin sources, but also authenticated source flows that are closer to real distribution scenarios.
* Market and source handling are becoming more structured, which is important for long-term maintainability and ecosystem growth.
* Installation reliability continues to improve in places that directly affect daily use.

### 为什么这个 Alpha 值得发布

* Rootless Store 开始不只支持公开源，也开始具备更接近真实分发场景的认证源接入能力。
* Market 与 Source 的处理方式正在变得更结构化，这对后续可维护性和生态扩展都很重要。
* 安装链路的稳定性也在继续提升，而且这些改动都直接影响日常使用体验。

---

### Known Issues & Next Steps

* Private source support is still in an early stage and may continue to evolve.
* Source authentication UX, market interaction details, and installation diagnostics are expected to improve further.
* Later alpha builds will continue hardening these distribution-related workflows.

### 已知问题与下一步计划

* 私有源支持目前仍处于早期阶段，后续仍可能继续调整。
* Source 认证体验、Market 交互细节，以及安装诊断能力还会继续完善。
* 后续 Alpha 版本会继续加固这条围绕分发与安装展开的核心工作流。
