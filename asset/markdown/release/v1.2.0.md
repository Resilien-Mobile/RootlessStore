# 第三方推送通知实验版

Welcome to Rootless Store v1.2.0!

This release is an experimental MVP focused on third-party push notifications. In v1.2.0, Rootless Store introduces its first external alert delivery workflow with Bark support, along with a dedicated settings screen for notification preferences. As an early functional test build, this version still contains many uncertainties and may have issues such as installation crashes or other unstable behaviors.

欢迎来到 Rootless Store v1.2.0！

这个版本是一个围绕第三方推送通知展开的实验性 MVP。v1.2.0 为 Rootless Store 带来了第一版面向设备外的告警推送能力，加入了 Bark 支持，并提供了独立的通知设置页面。由于这是一个早期功能测试版本，目前仍存在较多不确定因素，也可能出现安装闪退等不稳定问题。

---

### What's New in v1.2.0

* **Third-party Push Notification Support**:
    * Added the first third-party notification push workflow.
    * Plugin exit warnings can now be forwarded through Bark.
* **Dedicated Notification Settings Screen**:
    * Added a separate settings page for third-party notification configuration.
    * Users can now manage Bark-related settings in a more direct way.
* **Saved Notification Preferences**:
    * Bark API Key and warning notification preferences can now be saved and reused.
* **Settings UI Improvements**:
    * Refined the Settings list item structure to support more flexible trailing actions and controls.

### v1.2.0 更新内容

* **第三方推送通知支持**:
    * 新增了第一版第三方通知推送工作流。
    * 插件退出告警现在可以通过 Bark 推送出去。
* **独立通知设置页**:
    * 新增了独立的第三方通知设置页面。
    * 用户现在可以更直接地管理 Bark 相关配置。
* **通知偏好持久化**:
    * Bark API Key 与告警通知偏好现在可以被保存并复用。
* **设置页 UI 优化**:
    * 调整了 Settings 列表项结构，以支持更灵活的尾部操作与控制项。
