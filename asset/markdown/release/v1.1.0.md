# 本地监控与通知版

Welcome to Rootless Store v1.1.0!

This release focuses on local runtime monitoring and notification support. In v1.1.0, Rootless Store improves plugin status awareness on-device, making abnormal exits easier to notice and handle in time.

欢迎来到 Rootless Store v1.1.0！

这个版本的重点放在本地运行时监控与通知支持上。v1.1.0 进一步增强了设备侧的插件状态感知能力，让异常退出更容易被及时发现和处理。

---

### What's New in v1.1.0

* **Local Plugin Status Notifications**:
  Added plugin status notification support so abnormal runtime exits can be surfaced more clearly.
* **Process Exit Monitoring**:
  Rootless Store can now monitor plugin process exits and report abnormal terminations through the local notification path.
* **More Consistent Stop Behavior**:
  Stopping running plugins now follows the selected execution context more consistently.

### v1.1.0 更新内容

* **本地插件状态通知**:
  新增了插件状态通知支持，让异常运行退出能够被更明确地提示出来。
* **进程退出监控**:
  Rootless Store 现在可以监控插件进程退出情况，并通过本地通知路径汇报异常终止。
* **更一致的停止行为**:
  停止运行中插件时，现在会更一致地遵循当前选中的执行上下文。

### 重要提醒

### 下一步计划

* 下一个版本计划加入 **Bark** 和更广泛的第三方消息推送支持。
