# Shell 上下文偏好增强版

Welcome to Rootless Store v0.0.901!

This update focuses on making the Shell workflow more configurable and more practical in real use. In v0.0.901, Rootless Store introduces persistent Shell context preferences, applies those preferences directly to command execution, and adjusts the app's runtime strategy so more plugins can run in LIMITED environments without forcing users to escalate into Shell-level privileges.

欢迎来到 Rootless Store v0.0.901！

这个版本的重点，是让 Shell 工作流在实际使用中变得更可控、更贴近真实场景。v0.0.901 引入了可持久化的 Shell 上下文偏好设置，并将这些偏好直接应用到命令执行流程中；同时也调整了应用的运行策略，让更多插件可以在 LIMITED 环境下直接运行，而不必强制提权到 Shell 级别。

---

### What's New in v0.0.901

* **Persistent Shell Context Preferences**:
    * **Saved Shell Options**: Added persistent Shell preference storage so selected execution options can be remembered across app sessions.
    * **DataStore-backed Settings**: Shell context settings are now stored through a dedicated preference layer, improving consistency and future extensibility.
* **Shell Execution Behavior Enhancements**:
    * **`run-as` Toggle for ADB Shell**: Added an option to control whether ADB Shell commands should run with `run-as` behavior.
    * **Jump-to-Directory Option**: Added a Shell option to jump into the default plugin directory before running commands in applicable environments.
    * **Preferences Applied at Runtime**: Saved Shell context preferences are now read and applied directly when commands are executed.
* **Shell Screen Interaction Updates**:
    * **Context-aware Controls**: The Shell screen now exposes different option controls depending on the selected Shell environment, making the workflow more explicit.
* **LIMITED Runtime Strategy Adjustment**:
    * **Lower Target SDK for Broader Execution**: Adjusted the target SDK strategy so more plugins can execute under LIMITED environments.
    * **Reduced Privilege Escalation Pressure**: This helps avoid forcing users to escalate into Shell for many common plugin scenarios, lowering both mental overhead and practical usage cost.

### v0.0.901 更新内容

* **可持久化的 Shell 上下文偏好**:
    * **Shell 选项记忆**: 新增了可持久化的 Shell 偏好存储能力，让已选择的执行选项可以跨应用会话被记住。
    * **基于 DataStore 的设置层**: Shell 上下文设置现已通过独立的偏好存储层管理，为一致性和后续扩展打下基础。
* **Shell 执行行为增强**:
    * **ADB Shell 的 `run-as` 开关**: 为 ADB Shell 新增了是否启用 `run-as` 执行行为的控制选项。
    * **跳转目录选项**: 为适用的 Shell 环境新增了在执行命令前自动跳转到默认插件目录的能力。
    * **运行时应用偏好**: 已保存的 Shell 上下文偏好现在会在命令执行时被直接读取并应用。
* **Shell 页面交互更新**:
    * **按环境显示控制项**: Shell 页面会根据当前选择的 Shell 环境展示不同的选项控制，让执行流程更明确、更可见。
* **LIMITED 运行策略调整**:
    * **更低的 Target SDK 以扩大可执行范围**: 调整了 target SDK 相关策略，让更多插件可以在 LIMITED 环境下直接执行。
    * **减少对 Shell 提权的依赖**: 这让很多常见插件场景不再需要强制提权到 Shell，显著降低了用户的心智负担和实际使用成本。

---

### Key Features

* **Configurable Shell Workflow**: Rootless Store now gives users more direct control over how Shell commands are prepared and executed.
* **Persistent Execution Preferences**: Frequently used Shell options no longer need to be reconfigured every time the app is reopened.
* **More Plugins Usable in LIMITED Environments**: By adjusting the runtime strategy, Rootless Store can keep more plugin flows usable without immediately pushing users toward privilege escalation.
* **Lower User Burden**: Reducing the need for Shell-level escalation makes the platform easier to understand, easier to adopt, and cheaper to use in practice.

### 主要功能

* **可配置的 Shell 工作流**: Rootless Store 现在提供了更直接的控制能力，让用户能决定命令该如何被准备和执行。
* **可记忆的执行偏好**: 常用的 Shell 选项不再需要每次打开应用后重复设置。
* **更多插件可在 LIMITED 环境下运行**: 通过调整运行策略，Rootless Store 能让更多插件流程在不立即走向提权的情况下保持可用。
* **更低的用户负担**: 减少对 Shell 级提权的依赖，也就让整个平台更容易理解、更容易上手，并降低了实际使用成本。

### Known Issues & Future Plans

* This is still an early-stage refinement of the Shell option system, and option coverage may continue to expand in future versions.
* Some plugins and runtime paths may still require stronger privileges depending on device state and environment constraints.
* Future updates may continue improving LIMITED-environment coverage, Shell option localization, and more advanced execution presets.

### 已知问题与未来计划

* 这仍然是 Shell 选项系统的早期迭代版本，后续仍可能继续扩展可配置项的覆盖范围。
* 部分插件和运行路径仍可能因设备状态或环境限制，继续需要更高权限支持。
* 未来更新预计会继续提升 LIMITED 环境下的覆盖能力，并完善 Shell 选项的本地化和更高级的执行预设能力。
