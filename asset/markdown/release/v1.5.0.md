# Code Brick 快捷脚本工作流发布版

Welcome to Rootless Store v1.5.0!

This release introduces Code Brick, a new workspace for turning frequently used shell scripts into reusable actions. Instead of repeatedly entering the same commands, users can now create named Code Bricks, keep them in the app, preview their content, run them directly, and review the result in one place.

欢迎来到 Rootless Store v1.5.0！

这个版本正式引入了 Code Brick，一个用于把常用 Shell 脚本变成可复用操作的新工作区。用户不再需要反复输入相同命令，现在可以创建带名称的 Code Brick，将其保存在应用内、预览内容、直接运行，并在同一处查看执行结果。

---

### What's New in v1.5.0

* **New Code Brick Workspace**:
    * Added a dedicated Code Brick entry to the main navigation.
    * Common scripts can now be collected in one focused workspace instead of being scattered across Shell history or external notes.

* **Create and Save Reusable Scripts**:
    * Create a Code Brick by giving a script a name and its command content.
    * Saved Code Bricks remain available after reopening the app, making recurring tasks easier to reuse.

* **Card-based Script Preview**:
    * Each Code Brick shows its name and script content before execution.
    * Users can quickly review what a script will do and remove Code Bricks that are no longer needed.

* **Run and Review Results in One Place**:
    * Run a Code Brick directly from its card.
    * Execution results are shown in a dedicated result view, making output easier to review without leaving the workspace.

* **Navigation Experience Improvements**:
    * Code Brick is integrated into the main app flow as a first-class page.
    * Switching between Code Brick and other areas now keeps the navigation state more consistent.

### v1.5.0 更新内容

* **全新 Code Brick 工作区**:
    * 在主导航中新增了独立的 Code Brick 入口。
    * 常用脚本现在可以集中放在一个专属工作区中，不再分散在 Shell 历史或外部笔记里。

* **创建并保存可复用脚本**:
    * 用户可以为脚本填写名称和命令内容，创建一个 Code Brick。
    * 已保存的 Code Brick 在重新打开应用后仍然可用，让重复任务更容易复用。

* **卡片式脚本预览**:
    * 每个 Code Brick 都会展示名称和脚本内容。
    * 用户可以在运行前快速确认脚本，也可以删除不再需要的 Code Brick。

* **在同一处运行和查看结果**:
    * 可以直接从 Code Brick 卡片运行脚本。
    * 执行结果会在独立结果视图中展示，不需要离开当前工作区。

* **导航体验优化**:
    * Code Brick 已作为一级页面接入主应用流程。
    * 在 Code Brick 与其他页面之间切换时，导航状态会更加一致。

### Current Limitations & Next Steps

* **Editing Is Not Available Yet**:
    * Once a Code Brick is created, it cannot yet be edited.
    * Editing support is planned for the next release.
* **Execution Environment Selection Is Not Available Yet**:
    * Users cannot currently choose the execution environment for a Code Brick.
    * Environment selection support is planned for the next release.
* **Execution Status Is Not Clear Enough**:
    * Unlike ShellScreen, Code Brick does not yet use visual feedback to indicate whether execution succeeded or failed.
    * Users currently need to judge results from the output itself; clearer status feedback is planned for the next release.
* **Empty Output Handling**:
    * When execution has no visible output or final status, the result may currently display `Void`.
    * This behavior is planned to be improved in the `2.x` series.

### 当前局限与后续计划

* **暂不支持编辑**:
    * Code Brick 创建后，目前还无法再次修改。
    * 编辑能力计划在下一个版本中加入。
* **暂不支持选择执行环境**:
    * 用户目前无法为 Code Brick 自行选择执行环境。
    * 执行环境选择能力计划在下一个版本中加入。
* **执行状态反馈还不够明确**:
    * 与 ShellScreen 不同，Code Brick 目前还无法通过颜色等直观反馈区分执行成功或失败。
    * 用户现在需要通过输出内容自行判断，下一版本会加入更清晰的状态提示。
* **空输出处理限制**:
    * 当执行没有可见输出或最终状态时，当前结果可能会显示为 `Void`。
    * 这一行为计划在后续 `2.x` 系列中改进。
