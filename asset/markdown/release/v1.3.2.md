# 环境包动态图标支持版

Welcome to Rootless Store v1.3.2!

This release continues improving visual personalization across Rootless Store. In v1.3.2, dynamic icon rendering is extended from plugins to environment packages, allowing installed environments to display their own icons in the environment list.

欢迎来到 Rootless Store v1.3.2！

这个版本继续完善 Rootless Store 的个性化展示能力。v1.3.2 将动态图标渲染能力从插件扩展到了环境包，让已安装的环境也可以在环境列表中展示自己的图标。

---

### What's New in v1.3.2

* **Dynamic Environment Icon Rendering**:
    * Environment cards can now display icons from resolved URI values.
    * The environment list now uses the same dynamic icon component as plugin cards.
* **Local Environment Icon Path Support**:
    * Local environment icon paths are now resolved into usable file URIs before rendering.
    * This improves compatibility with icons packaged inside environment directories.
* **Remote URI Compatibility**:
    * Remote HTTP / HTTPS icon URIs are preserved and can continue to be loaded dynamically.
    * Local paths and remote URIs are now handled more consistently across plugins and environments.

### v1.3.2 更新内容

* **环境包动态图标渲染**:
    * 环境卡片现在可以展示解析后的 URI 图标资源。
    * 环境列表现在复用了与插件卡片一致的动态图标组件。
* **本地环境图标路径支持**:
    * 本地环境图标路径现在会在渲染前转换为可用的文件 URI。
    * 这提升了对环境包目录内自带图标资源的兼容性。
* **远端 URI 兼容性**:
    * 远端 HTTP / HTTPS 图标 URI 会被保留，并可以继续被动态加载。
    * 本地路径与远端 URI 现在在插件和环境包之间有了更一致的处理方式。

---

### Known Issues & Future Plans

* Environment icon loading still depends on valid icon paths or accessible remote resources.
* If an environment icon fails to load, Rootless Store will continue falling back to the default icon.

### 已知问题与未来计划

* 环境图标加载仍依赖有效的图标路径，或可访问的远端资源。
* 如果环境图标加载失败，Rootless Store 仍会回退到默认图标。
