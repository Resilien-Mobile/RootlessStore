# 执行页控制补完版

Welcome to Rootless Store v0.0.903!

This is a small completion update focused on the Execute screen. In v0.0.903, the top app bar actions are now wired up, so users can stop the current plugin process, share execution logs, and return from the screen more naturally.

欢迎来到 Rootless Store v0.0.903！

这是一次体量很小的补完更新，重点放在 Execute 页面。v0.0.903 把顶部操作栏里原本未完成的控制补齐了，用户现在可以直接停止当前插件进程、分享执行日志，并更自然地返回上一级页面。

---

### What's New in v0.0.903

* **Execute Screen Controls Completed**:
    * **Stop Action Works**: The stop button can now abort the currently running plugin process.
    * **Share Action Works**: The share button can now export the current execution log as plain text.
    * **Back Action Works**: The back button now returns from the Execute screen properly.

### v0.0.903 更新内容

* **Execute 页面控制补完**:
    * **停止按钮可用**: 停止按钮现在可以直接中止当前运行中的插件进程。
    * **分享按钮可用**: 分享按钮现在可以把当前执行日志导出为纯文本。
    * **返回按钮可用**: 返回按钮现在会正确退出 Execute 页面。
