# 第三方推送配置增强版

Welcome to Rootless Store v1.2.1!

This release continues the third-party notification work introduced in v1.2.0 and focuses on making the Bark configuration flow more practical. In v1.2.1, Rootless Store improves the notification settings form, adds support for custom notification titles, and prepares additional configuration space for future self-built server workflows.

欢迎来到 Rootless Store v1.2.1！

这个版本延续了 v1.2.0 开始的第三方通知推送方向，重点放在让 Bark 配置流程更接近日常使用。v1.2.1 优化了通知设置表单，加入了自定义通知标题支持，并为后续自建服务器相关能力预留了更多配置空间。

---

### What's New in v1.2.1

* **Improved Bark Settings Form**:
    * Refined the third-party notification settings screen.
    * The Bark API Key is now masked by default for better privacy during configuration.
* **Custom Notification Title Support**:
    * Added an optional notification title field.
    * Saved custom titles can now be used when Bark push alerts are sent.
* **More Flexible Notification Preferences**:
    * Added an optional self-built server field for future expansion.
    * Notification preference saving and reuse are now more complete.

### v1.2.1 更新内容

* **Bark 设置表单优化**:
    * 进一步优化了第三方通知设置页面。
    * Bark API Key 现在默认以隐藏方式显示，配置时更符合隐私使用习惯。
* **自定义通知标题支持**:
    * 新增了可选的通知标题字段。
    * 已保存的自定义标题现在可以实际用于 Bark 推送告警。
* **更灵活的通知偏好配置**:
    * 新增了可选的自建服务器字段，为后续扩展预留配置入口。
    * 通知偏好的保存与复用能力现在更加完整。
