# Rootless Store v2.4.1 发布：让插件运行得更安心

Welcome to Rootless Store v2.4.1!

This update focuses on making plugin execution and management clearer and more reliable. It connects the existing `executableFiles` Manifest field, enabling plugins to use multiple script files together and share context.

Unit test coverage has also been expanded further to help catch problems earlier and make future releases more dependable.

欢迎来到 Rootless Store v2.4.1！

这次更新聚焦于让插件运行和管理更加清晰、可靠。Manifest 中原本就存在的 `executableFiles` 字段现在正式接入，插件可以一次激活多个 Script 文件，并让它们之间共享上下文。

本版本也进一步扩大了单元测试覆盖范围，帮助项目更早发现问题，为后续更新提供更可靠的保障。

---

### What's New in v2.4.1

* **Chained Script Calls**:
    * The existing `executableFiles` field in the Manifest is now connected and ready to use.
    * Plugins can activate multiple script files and share context between them.
    * This makes it easier to organize larger, more structured plugin projects.

* **Contract-Driven Execution Environments**:
    * Plugin execution now follows the environment declared in the Manifest.
    * When an environment is specified, Rootless Store will respect that declaration instead of silently falling back to another environment.
    * If the required environment is unavailable, users receive clearer feedback about what needs attention.

* **Clearer Shizuku Permission Feedback**:
    * When a plugin requires Shizuku but permission or the service is unavailable, the app now displays a clear prompt.
    * Users can identify the problem and take the appropriate steps before trying again.
    * Fixed an issue that could cause a crash while checking Shizuku availability.

* **Plugin Installation and Removal Improvements**:
    * Improved support for plugins that need to run additional files, reducing installation and execution problems.
    * Plugin removal failures now provide clearer feedback, including when Shizuku permission is unavailable.
    * Removed the plugin badge editing entry to simplify the management interface.

### v2.4.1 更新内容

* **支持链式调用**:
    * Manifest 中原本就存在的 `executableFiles` 字段现在正式接入，可以正常使用。
    * 插件可以一次激活多个 Script 文件，并在脚本之间共享上下文。
    * 这让插件更容易拆分和组织，支持更具工程性的开发方式。

* **契约驱动的执行环境**:
    * 插件执行现在更加依赖 Manifest 中声明的运行环境。
    * 当插件指定了执行环境时，Rootless Store 会按照声明执行，不再像以前一样回退到其他环境。
    * 如果所需环境不可用，用户会收到更加明确的提示，了解需要处理的问题。

* **Shizuku 授权提示更加明确**:
    * 当插件需要 Shizuku，但授权或服务不可用时，应用现在会给出明确提示。
    * 用户可以先了解问题并完成相应处理，再重新尝试运行。
    * 修复了检查 Shizuku 可用状态时可能导致闪退的问题。

* **插件安装与卸载优化**:
    * 改进了对需要运行额外文件的插件的支持，减少安装或运行过程中遇到的问题。
    * 插件卸载失败时，现在会提供更加清晰的反馈，包括 Shizuku 授权不可用的情况。
    * 移除了插件标记编辑入口，让管理界面更加简洁。
