# 设置页 Beta 预览版

Welcome to Rootless Store v1.0.0-beta!

This release is a visual and structural beta focused on the new Settings experience. In today’s build, Rootless Store introduces the first complete pass of the Settings screen design and finishes the Permission section first, while the broader functional expansion is planned for v1.0.5.

欢迎来到 Rootless Store v1.0.0-beta！

这个版本是一次偏视觉与结构层面的 Beta 预览，重点放在全新的设置页体验上。当前这次更新，Rootless Store 完成了 Settings 页面的第一版整体设计，并优先把 Permission 部分先做完整；更多功能性的扩展，将放到后续的 v1.0.5 中继续推进。

---

### What's New in v1.0.0-beta

* **New Settings Screen**:
    * Added the first full Settings screen entry and layout structure.
    * Introduced a clearer section-based organization for General, Source, Permission, and About.
* **Permission Section Completed First**:
    * The Permission part is the main completed section in this beta.
    * Added direct shortcuts for common permission-related system pages, such as file access, notification, battery, and related permission controls.
* **Style-first Beta Pass**:
    * This release mainly focuses on visual structure, list presentation, and interaction layout for Settings.
    * It is intended as the first polished surface for the upcoming settings workflow.

### v1.0.0-beta 更新内容

* **全新设置页**:
    * 新增了第一版完整的 Settings 页面入口与页面结构。
    * 通过分区方式初步整理了 General、Source、Permission、About 等模块。
* **优先完成 Permission 部分**:
    * Permission 是这次 Beta 中最先完整做完的部分。
    * 新增了常用权限相关系统页面的快捷跳转入口，包括文件访问、通知、电池，以及相关权限控制项。
* **以样式为主的 Beta 打磨**:
    * 这次更新主要聚焦于 Settings 页面的视觉结构、列表呈现和交互布局。
    * 它更像是后续完整设置工作流的第一版成型外观。

---

### Beta Notes

* This release is intentionally focused on style and structure first.
* Today’s completed portion is mainly the Permission section.
* More functional work for Settings is planned for v1.0.5.

### Beta 说明

* 这个版本是有意先以样式和结构为主来推进的。
* 今天实际完成度最高、真正先落下来的部分，主要是 Permission 模块。
* 更多与 Settings 相关的功能补完，会在后续的 v1.0.5 中继续加入。

---

### Known Issues & Next Steps

* Some Settings sections are still in a preparatory stage.
* Functional expansion beyond the current Permission workflow is planned for v1.0.5.
* Future updates will continue turning this Settings screen from a styled shell into a fuller control center.

### 已知问题与下一步计划

* 目前 Settings 的部分分区仍然处于准备阶段。
* 除 Permission 之外的更多功能性内容，计划在 v1.0.5 中继续补齐。
* 后续更新会继续把这个设置页，从“样式成型”推进到“功能完整”的控制中心。
