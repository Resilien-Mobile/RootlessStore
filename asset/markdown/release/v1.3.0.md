# 插件个性化图标支持版

Welcome to Rootless Store v1.3.0!

This release focuses on improving plugin personalization and visual recognition. In v1.3.0, Rootless Store adds dynamic plugin icon rendering, allowing local plugins to display their own icons in the plugin list instead of always falling back to the default extension icon.

欢迎来到 Rootless Store v1.3.0！

这个版本的重点，是提升插件的个性化展示与识别体验。v1.3.0 新增了动态插件图标渲染能力，让本地插件可以在插件列表中展示自己的图标，而不是始终使用默认扩展图标。

---

### What's New in v1.3.0

* **Dynamic Plugin Icon Rendering**:
    * Added support for loading plugin icons dynamically in the local plugin list.
    * Plugin cards can now display icons provided by the plugin itself.
* **Local Plugin Icon Path Support**:
    * Local plugin icon paths are now resolved into usable file URIs before rendering.
    * This improves compatibility with icons packaged inside local plugin directories.
* **Fallback Icon Handling**:
    * When a plugin does not provide an icon, or when icon loading fails, Rootless Store will continue using the default plugin icon.
    * This keeps the plugin list stable while allowing richer visual customization.

### v1.3.0 更新内容

* **动态插件图标渲染**:
    * 新增了本地插件列表中的动态图标加载能力。
    * 插件卡片现在可以展示插件自身提供的图标。
* **本地插件图标路径支持**:
    * 本地插件图标路径现在会在渲染前转换为可用的文件 URI。
    * 这提升了对插件目录内自带图标资源的兼容性。
* **默认图标回退处理**:
    * 当插件没有提供图标，或图标加载失败时，Rootless Store 会继续使用默认插件图标。
    * 这能在支持个性化展示的同时，保持插件列表显示稳定。

---

### Known Issues & Future Plans

* Plugin icon support is still in an early stage, and more icon formats or display details may continue to be refined.
* The next version is planned to support full URI-based icons, allowing icons to be loaded dynamically from remote sources and reducing the mental overhead for plugin developers.
* Future versions may continue improving plugin personalization, including richer plugin metadata and more polished plugin card presentation.

### 已知问题与未来计划

* 插件图标支持仍处于早期阶段，后续可能会继续完善图标格式兼容与展示细节。
* 下一个版本计划加入完整 URI 图标支持，让图标可以从远端动态获取，从而降低插件开发者的心智负担。
* 未来版本会继续增强插件个性化能力，包括更丰富的插件元信息和更精细的插件卡片展示。
