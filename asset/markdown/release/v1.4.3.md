# 架构迁移与 Shell 体验增强版

Welcome to Rootless Store v1.4.3!

This release is a large migration and stability update. In v1.4.3, Rootless Store reorganizes several core app flows, improves Shell command continuity, and cleans up many old rough edges around plugins, environments, market installation, and project presentation. The goal of this version is not just to add features, but to make the app easier to keep stable as it continues to grow.

欢迎来到 Rootless Store v1.4.3！

这是一次体量较大的迁移与稳定性更新。v1.4.3 对应用的多条核心流程进行了重新整理，同时增强了 Shell 命令的连续使用体验，并清理了插件、环境包、市场安装和项目展示中的许多历史细节问题。这个版本的重点不只是增加功能，而是让 Rootless Store 在继续扩展时更容易保持稳定和一致。

---

### What's New in v1.4.3

* **Shell Command Context Memory**:
    * Shell now remembers the current working context more naturally between commands.
    * After changing directories, following commands should behave closer to a real continuous shell session.
    * App Shell, ADB Shell, and Root Shell now feel more consistent when running repeated commands.

* **Plugin and Environment Flow Migration**:
    * Plugin and environment handling have been reorganized to behave more consistently.
    * Local install, market install, enable, disable, and uninstall flows now have a cleaner foundation.
    * This helps reduce hidden inconsistencies between plugins and environment packages.

* **Market and Runtime Flow Cleanup**:
    * Market installation and runtime setup flows have been adjusted to better match the new app structure.
    * Users should see fewer odd edge cases when installing or managing modules from different entry points.

* **Project Presentation Cleanup**:
    * README screenshots and roadmap content have been refreshed to match the current app direction.
    * Expired release notes and outdated preview materials have been removed.

### v1.4.3 更新内容

* **Shell 命令上下文记忆**:
    * Shell 现在可以更自然地记住连续命令之间的当前上下文。
    * 切换目录后，后续命令会更接近真实连续 Shell 会话的使用体验。
    * App Shell、ADB Shell 和 Root Shell 在连续执行命令时表现更加一致。

* **插件与环境包流程迁移**:
    * 插件与环境包相关流程经过重新整理，行为现在更加一致。
    * 本地安装、市场安装、启用、禁用、卸载等流程有了更清晰的基础。
    * 这有助于减少插件和环境包之间过去容易出现的隐性不一致问题。

* **Market 与运行流程清理**:
    * Market 安装与运行准备流程已根据新的应用结构重新调整。
    * 从不同入口安装或管理模块时，用户遇到异常边缘情况的概率会更低。

* **项目展示内容清理**:
    * README 截图和路线图内容已更新，以匹配当前应用状态。
    * 过期的发布说明和旧预览资料已被清理。

---

### Bug Fixes & Experience Polish

* Fixed cases where Shell commands could feel disconnected between runs.
* Reduced repeated manual work when using Shell commands across the same directory.
* Improved consistency between plugin management and environment management.
* Cleaned up old screen code and stale project materials that no longer matched the current app.
* The `1.4.x` series will continue focusing on migration follow-up fixes, stability, and detail-level consistency.

### Bug 修复与体验打磨

* 修复了 Shell 命令连续执行时上下文容易断开的体验问题。
* 减少了在同一目录下反复执行命令时需要重复手动切换路径的情况。
* 改善了插件管理与环境包管理之间的一致性。
* 清理了不再匹配当前应用状态的旧页面代码和过期项目资料。
* 后续 `1.4.x` 版本会继续围绕迁移后的细节问题、稳定性和一致性进行修复。
