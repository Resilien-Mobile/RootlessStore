# 多语言与设置入口修复版

Welcome to Rootless Store v1.4.2!

This release continues the detail-level polish of the `1.4.x` series. In v1.4.2, Rootless Store improves localized text coverage across more screens and fixes the navigation behavior around third-party notification settings, making the app feel more complete and consistent in daily use.

欢迎来到 Rootless Store v1.4.2！

这个版本继续延续 `1.4.x` 系列的细节打磨方向。v1.4.2 补齐了更多页面的多语言文案，并修复了第三方通知设置相关的导航体验，让应用在日常使用中显得更完整、更一致。

---

### What's New in v1.4.2

* **Improved Localization Coverage**:
    * Added more localized text for English, Simplified Chinese, and Traditional Chinese.
    * Version update prompts, Shell options, and third-party notification settings now display more consistently across supported languages.
* **Third-party Notification Settings Navigation Fix**:
    * Fixed the navigation grouping for the third-party notification settings page.
    * Returning from notification settings now feels more natural and better aligned with the Home / Settings flow.
* **Small UI Text Polish**:
    * Reduced remaining hard-coded or inconsistent screen text.
    * Improved wording consistency in places users interact with frequently.

### v1.4.2 更新内容

* **多语言覆盖补齐**:
    * 补充了更多英文、简体中文与繁体中文文案。
    * 版本更新提示、Shell 选项、第三方通知设置等内容，现在在不同语言下显示更加一致。
* **第三方通知设置导航修复**:
    * 修复了第三方通知设置页的导航归属问题。
    * 从通知设置页返回时，现在会更自然，也更符合 Home / Settings 的使用路径。
* **界面文案细节打磨**:
    * 减少了仍然残留的不一致界面文案。
    * 优化了一些用户经常接触到的页面文字体验。

---

### Bug Fixes & Experience Polish

* Fixed a navigation issue where third-party notification settings did not behave like part of the expected Home / Settings flow.
* Improved language consistency across several visible screens.
* The `1.4.x` series will continue focusing on these small but noticeable consistency fixes.

### Bug 修复与体验打磨

* 修复了第三方通知设置页没有正确归入预期 Home / Settings 流程的问题。
* 改善了多个可见页面的语言一致性。
* 后续 `1.4.x` 版本会继续聚焦这类细小但明显的一致性修复。

感谢你持续关注 Rootless Store，也感谢一起推动应用的日常细节变得更好。
