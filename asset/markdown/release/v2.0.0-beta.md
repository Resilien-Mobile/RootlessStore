# Rootless Store 2.0 Beta 发布

Welcome to Rootless Store v2.0.0-beta!

Rootless Store v2.0.0-beta is a large Beta release after the first 2.0 Alpha. This version focuses on making the new 2.0 workflow more usable in real scenarios: native shell-style plugins are now supported more directly, and Rootless Store starts exploring Magisk module compatibility.

欢迎来到 Rootless Store v2.0.0-beta！

Rootless Store v2.0.0-beta 是 2.0 Alpha 之后的一次大型 Beta 更新。这个版本重点让 2.0 的新工作流更接近真实可用：现在开始更直接地支持原生 Shell 类型插件，Rootless Store 也开始探索 Magisk 模块兼容能力。

---

### What's New in v2.0.0-beta

* **Native Shell Plugin Support**:
    * Rootless Store now supports native shell-style plugins more directly.
    * The old active run-as downgrade behavior has been removed for this workflow.
    * Shell plugins can now execute shell-level commands in a way that better matches user expectations, instead of feeling like they are running through an unnecessary permission layer.

* **Magisk Module Compatibility Preview**:
    * Rootless Store can now recognize Magisk-style module packages in more cases.
    * Supported modules can be converted into Rootless Store Shell plugins for testing.
    * This is an early compatibility step, intended to explore how existing Android module ecosystems can connect with Rootless Store.

* **Quick Tile and Notification Visual Fixes**:
    * Quick Settings tiles now use a more appropriate running-action icon.
    * Plugin status notifications also use the updated icon.
    * These visual changes make automation and execution states easier to recognize at a glance.

### v2.0.0-beta 更新内容

* **支持原生 Shell 类型插件**:
    * Rootless Store 现在开始更直接地支持原生 Shell 类型插件。
    * 这一工作流取消了过去主动 `run-as` 降权的行为。
    * Shell 插件现在可以更贴近用户主观预期地执行 Shell 层指令，不再像隔着一层权限外壳“隔靴搔痒”。

* **Magisk 模块兼容预览**:
    * Rootless Store 现在可以在更多情况下识别 Magisk 风格的模块包。
    * 支持的模块可以被转换为 Rootless Store Shell 插件进行测试。
    * 这是一个早期兼容能力，用于探索现有 Android 模块生态如何接入 Rootless Store。

* **快捷磁贴与通知视觉修复**:
    * 快捷设置磁贴现在使用更符合“运行”语义的图标。
    * 插件状态通知也同步使用了新的图标。
    * 自动化和执行状态在视觉上会更容易识别。

---

### Beta & Compatibility Notice

> [!WARNING]
> Rootless Store v2.0.0-beta is still a Beta release. Shell plugin support and Magisk module compatibility are not guaranteed to work with every package.

If you are using important 1.x plugins or environment packages, please keep backups before testing this version. The 2.0 series is still reshaping plugin installation, execution, and compatibility behavior.

Magisk module support in this version should be considered experimental. Some modules may not install, may not run as expected, or may require future adaptation.

### Beta 与兼容提醒

> [!WARNING]
> Rootless Store v2.0.0-beta 仍然是 Beta 版本。Shell 插件支持和 Magisk 模块兼容能力，并不保证适用于所有包。

如果你仍在使用重要的 1.x 插件或环境包，请在测试此版本前保留备份。2.0 系列仍在重塑插件安装、执行和兼容行为。

本版本中的 Magisk 模块支持应视为实验性能力。部分模块可能无法安装、无法按预期运行，或需要在后续版本中继续适配。
