# 更新检测支持版

Welcome to Rootless Store v1.0.5!

This release continues the Settings work started in the beta stage and adds the first practical piece of functionality: version update detection. In v1.0.5, Rootless Store can remember the update-check preference, fetch the latest release tag from GitHub, and show a version prompt on the Home screen when a newer release is available.

欢迎来到 Rootless Store v1.0.5！

这个版本延续了 Beta 阶段开始的 Settings 方向，并补上了第一块真正可用的功能：版本更新检测。v1.0.5 现在可以记住“是否检查更新”的设置，从 GitHub 获取最新版本标签，并在首页检测到新版本时显示更新提示。

---

### What's New in v1.0.5

* **Update Check Support**:
    * Added the first version update detection flow.
    * The app can now fetch the latest release tag from GitHub.
* **Settings Integration**:
    * Added an auto-check latest version preference in Settings.
    * The preference is saved and reused across sessions.
* **Home Screen Prompt**:
    * When a newer version is detected, the Home screen can now show a version update card.
    * Tapping the card opens the latest GitHub release page.

### v1.0.5 更新内容

* **更新检测支持**:
    * 新增了第一版版本更新检测流程。
    * 应用现在可以从 GitHub 获取最新版本标签。
* **与 Settings 联动**:
    * 在 Settings 中加入了“自动检测最新版本”选项。
    * 该选项会被保存，并在后续启动时继续生效。
* **首页更新提示**:
    * 当检测到新版本时，Home 页面现在会显示更新提示卡片。
    * 点击该卡片后，可以直接跳转到 GitHub 的最新发布页。

---

### Notes

* This release focuses on update detection, not in-app update installation.
* It is the first functional follow-up to the Settings foundation introduced in the beta release.

### 说明

* 这个版本聚焦的是“检测更新”，并不包含应用内自动安装更新。
* 它可以看作是对 Beta 阶段 Settings 基础结构的第一轮功能补完。

---

### Known Issues & Next Steps

* The current flow only checks and jumps to the release page.
* Later versions may continue improving update experience and related settings behaviors.

### 已知问题与下一步计划

* 当前流程只负责检测更新并跳转到发布页。
* 后续版本会继续完善更新体验以及相关设置行为。
