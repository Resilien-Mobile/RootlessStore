# Code Brick 多语言体验优化版

Welcome to Rootless Store v1.5.2!

This release improves the Code Brick experience with better localization and a clearer page presentation. Code Brick now feels more consistent across different languages, and the page is easier to recognize and use at a glance.

欢迎来到 Rootless Store v1.5.2！

这个版本优化了 Code Brick 的多语言体验和页面展示。Code Brick 现在在不同语言环境下会更加一致，页面识别度也更高，使用起来更清晰。

---

### What's New in v1.5.2

* **Code Brick Localization**:
    * Code Brick now supports localized text across its main screen, editor, settings, action buttons, and result view.
    * Users using Simplified Chinese or Traditional Chinese will see a more complete localized experience.

* **Clearer Code Brick Page**:
    * The Code Brick page now uses a more prominent title area.
    * A short subtitle has been added to better explain the purpose of the page.

* **More Consistent User Flow**:
    * Creation, editing, execution, settings, and deletion labels are now more consistent with the rest of the app.
    * The experience is smoother for users who rely on localized UI text.

### v1.5.2 更新内容

* **Code Brick 多语言补全**:
    * Code Brick 的主页面、编辑弹窗、设置弹窗、操作按钮和执行结果等文案现在都支持本地化。
    * 使用简体中文或繁体中文的用户，会看到更完整的本地化体验。

* **Code Brick 页面更清晰**:
    * Code Brick 页面现在使用了更醒目的标题区域。
    * 页面增加了简短副标题，用来更明确地说明这个页面的用途。

* **使用流程更统一**:
    * 创建、编辑、执行、设置、删除等操作文案现在和应用其他页面更加一致。
    * 对依赖本地化界面的用户来说，整体使用体验会更顺滑。
