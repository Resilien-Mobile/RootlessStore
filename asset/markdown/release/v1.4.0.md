# 大规模稳定性修复版

Welcome to Rootless Store v1.4.0!

This release is a large stability-focused update. In v1.4.0, Rootless Store fixes many long-standing rough edges around navigation, plugin execution output, startup recovery, and host status display, making the app feel more consistent and predictable in daily use.

欢迎来到 Rootless Store v1.4.0！

这是一次以稳定性和体验修复为核心的大版本更新。v1.4.0 修复了大量此前存在的细节问题，重点覆盖页面切换、插件执行输出、启动恢复、宿主状态显示等多个日常使用场景，让应用整体表现更加稳定、连贯和可预期。

---

### What's New in v1.4.0

* **Smoother Navigation Experience**:
    * Improved screen switching across Home, Plugin, Market, Shell, Settings, Execute, Shizuku, and third-party notification pages.
    * Reduced cases where navigation state could feel inconsistent after entering or leaving deeper pages.
* **Cleaner Execute Screen Output**:
    * Improved how ExecuteScreen handles plugin output and execution results.
    * Reduced cases where multiple output streams could interfere with each other, making logs easier to follow.
* **Startup Recovery Improvements**:
    * Rootless Store now handles unfinished plugin execution records more cleanly when the app starts.
    * This helps avoid stale plugin states after abnormal exits, crashes, or forced app restarts.
* **Cleaner Plugin Status Handling**:
    * Plugins that were left in an uncertain running state can now be cleaned up more reliably.
    * This reduces cases where a plugin appears to still be running even though the actual process has already ended.
* **More Timely Host Status Updates**:
    * Shizuku, ADB Shell, and overall host status now refresh more continuously.
    * Status shown on Home and Shell-related areas should better reflect the current device environment.

### v1.4.0 更新内容

* **更顺畅的页面切换体验**:
    * 优化了 Home、Plugin、Market、Shell、Settings、Execute、Shizuku、第三方通知等页面之间的切换体验。
    * 减少了进入或退出深层页面后，页面状态不一致的问题。
* **更清晰的 Execute 页面输出**:
    * 优化了 ExecuteScreen 对插件输出和执行结果的处理方式。
    * 减少了多路输出互相干扰的问题，让执行日志更容易阅读和追踪。
* **启动恢复优化**:
    * Rootless Store 现在会在应用启动时更干净地处理未完成的插件执行记录。
    * 这有助于减少异常退出、闪退或强制重启后遗留的状态问题。
* **更干净的插件状态处理**:
    * 对于此前遗留在不确定运行状态中的插件，现在会有更可靠的清理处理。
    * 这可以减少“插件看起来还在运行，但实际进程已经结束”的情况。
* **更及时的宿主状态刷新**:
    * Shizuku、ADB Shell 以及整体宿主状态现在会更持续地刷新。
    * Home 和 Shell 相关区域显示的状态，会更贴近当前设备环境。

### Bug Fixes & Experience Polish

* Fixed many small but noticeable issues that could make the app feel inconsistent.
* Improved behavior after abnormal exits, app restarts, repeated navigation, and ExecuteScreen output updates.
* Reduced stale states in plugin execution and device status display.
* The `1.4.x` series will continue focusing on stability, consistency, and detail-level bug fixes.

### Bug 修复与体验打磨

* 修复了大量此前容易造成体验不一致的细节问题。
* 改善了异常退出、应用重启、反复切换页面，以及 ExecuteScreen 输出刷新时的状态表现。
* 减少了插件执行状态和设备状态显示中的残留问题。
* 后续 `1.4.x` 版本会继续聚焦稳定性、一致性，以及这类“强迫症”级别的细节 Bug 修复。
