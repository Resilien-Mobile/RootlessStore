# Rootless Store v2.3.0 发布：走得稳，才能稳更久

Welcome to Rootless Store v2.3.0!

The gap between v2.2.2 and v2.3.0 has indeed been longer than usual, but development has not been standing still.

v2.3.0 is the result of one of the largest refactoring efforts in Rootless Store so far. Instead of focusing entirely on visible new features, this period was spent reorganizing the major capabilities of the application so that each part can be observed more clearly, reused more consistently, and improved with less uncertainty.

The first benefit users can directly experience is clearer error feedback. When something fails, Rootless Store can now explain what happened instead of leaving users with a generic failure or no useful response.

This release also introduces initial test matrix support. The current coverage is only a starting point, but future release notes will include test matrix details directly, making it clear which scenarios have been verified and which areas still require attention.

欢迎来到 Rootless Store v2.3.0！

从 v2.2.2 到 v2.3.0，这次更新的间隔确实比以往更长，但这段时间并不是停滞。

v2.3.0 是 Rootless Store 迄今为止规模最大的一轮重构成果之一。这段时间没有将全部精力放在看得见的新功能上，而是重新梳理了应用中的各项能力，让不同模块变得更加可观测、更加可复用，也让后续的问题定位和功能迭代拥有更稳定的基础。

用户最先能够直接感受到的增益，就是错误现在终于一目了然了。当某项操作失败时，Rootless Store 会尽可能说明发生了什么，而不是只留下一个笼统的“失败”，或者没有任何有效反馈。

与此同时，初步测试矩阵也正式加入。目前的覆盖范围仍然只是起点，后续版本会在 Release 中直接附上测试矩阵详情，明确展示哪些场景已经完成验证、哪些部分仍然需要注意。

### What's New in v2.3.0

* **Errors Are Now Clear at a Glance**:
    * Plugin and environment installation failures now provide clearer and more specific explanations.
    * Rootless Store can better distinguish between unsupported packages, unreadable package information, damaged content, failed installation preparation, and unavailable execution environments.
    * Shell plugins and compatible Magisk-style packages also receive more useful failure feedback.
    * Error dialogs now present an understandable summary first while retaining detailed information for troubleshooting and issue reports.

* **Initial Test Matrix Support**:
    * Rootless Store has started adding repeatable checks for important application workflows.
    * These checks help identify unexpected behavior before a release reaches users.
    * The current test coverage is still at an early stage and does not yet represent every device, environment, or usage scenario.
    * Future release notes will include test matrix details directly so users and developers can understand the verified scope of each version.

* **Clearer Code Brick Import Feedback**:
    * Importing a Code Brick from the clipboard now reports when the clipboard is empty.
    * Invalid or incomplete Code Brick content produces a clear error instead of ending without explanation.
    * Users can understand what needs to be corrected before trying the import again.

* **More Focused Settings Navigation**:
    * The Settings and third-party notification pages no longer retain the main bottom navigation bar.
    * A clear back action now returns users to the previous page.
    * Secondary settings pages feel more focused and leave more room for their actual content.

* **Network Dashboard Visual Fixes**:
    * Wi-Fi, mobile network, and VPN connections now use more accurate icons.
    * Unknown or uncommon network interfaces are no longer incorrectly presented as Wi-Fi.
    * Devices with multiple network interfaces are easier to understand at a glance.

### v2.3.0 更新内容

* **错误现在一目了然**:
    * 插件与环境包安装失败时，现在会提供更加清晰、具体的说明。
    * Rootless Store 可以更好地区分无法识别的包、无法读取的信息、损坏的内容、安装准备失败以及运行环境不可用等情况。
    * Shell 插件和兼容的 Magisk 风格包也拥有了更加明确的失败反馈。
    * 错误弹窗会先给出容易理解的概括，同时保留详细信息，方便用户自行排查或提交 Issue。

* **初步测试矩阵支持**:
    * Rootless Store 已经开始为重要的应用流程加入可以重复执行的验证。
    * 这些检查可以帮助项目在版本发布前，更早发现意料之外的行为变化。
    * 当前测试覆盖仍处于初步阶段，暂时无法代表所有设备、运行环境和使用场景。
    * 后续版本会在 Release 中直接附上测试矩阵详情，让用户与开发者都能清楚了解每个版本已经验证的范围。

* **Code Brick 导入反馈更加明确**:
    * 从剪贴板导入 Code Brick 时，如果剪贴板为空，现在会直接说明原因。
    * 内容无效或不完整时，也会显示明确错误，而不是没有解释地结束操作。
    * 用户可以知道需要修改什么，再重新尝试导入。

* **更加专注的设置页导航**:
    * 设置页和第三方通知设置页不再继续显示主页面的底部导航栏。
    * 页面现在提供清晰的返回入口，可以直接回到上一级。
    * 二级设置页面更加专注，也为实际内容留出了更多空间。

* **网络看板视觉修复**:
    * Wi-Fi、移动网络和 VPN 连接现在会显示更加准确的图标。
    * 未知或较少见的网络接口不再被错误显示为 Wi-Fi。
    * 面对多网卡、多网络环境时，各类连接会更加容易辨认。
