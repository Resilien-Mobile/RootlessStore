# 2.0.0 Migration 过渡版

Welcome to Rootless Store v1.6.0!

Rootless Store v1.6.0 is a `2.0.0-migration` transitional release. It is mainly prepared for users who need to back up, share, or export existing plugins and environment packages before the upcoming 2.x series.

If your current 1.x version is working well and you do not need migration preparation yet, you can install this version only when needed.

欢迎来到 Rootless Store v1.6.0！

Rootless Store v1.6.0 是一个 `2.0.0-migration` 过渡版本。它主要面向需要在 2.x 系列到来前，提前备份、分享或导出现有插件与环境包的用户。

如果你当前的 1.x 版本使用稳定，并且暂时不需要迁移准备，可以按需再安装这个版本。

---

### What's New in v1.6.0

* **Plugin Sharing and Export**:
    * Local plugin cards now support long-press actions.
    * Users can share or export installed plugins as zip packages through the system share panel.

* **Environment Package Sharing and Export**:
    * Environment package cards now also support long-press actions.
    * Users can export environment packages in the same way, making it easier to prepare backups before 2.0.

* **Secondary Action Menu**:
    * Long-pressing a card now opens a focused action menu.
    * Share, return, and delete actions are now separated from normal card browsing, reducing accidental operations.

* **Migration Preparation for 2.0**:
    * This release brings part of the 2.0 preparation workflow to the current 1.x series.
    * Users can back up important plugins and environments earlier, instead of waiting until the 2.x migration window.

### v1.6.0 更新内容

* **插件分享与导出**:
    * 本地插件卡片现在支持长按操作。
    * 用户可以通过系统分享面板，将已安装插件分享或导出为 zip 包。

* **环境包分享与导出**:
    * 环境包卡片现在同样支持长按操作。
    * 用户可以用相同方式导出环境包，更方便地在 2.0 到来前提前备份。

* **二级操作菜单**:
    * 长按卡片后会进入独立的操作菜单。
    * 分享、返回、删除等操作与普通浏览分离，降低误触成本。

* **为 2.0 迁移提前准备**:
    * 这个版本将部分 2.0 前置准备能力下放到了现有 1.x 系列。
    * 用户可以更早备份重要插件和环境包，不必等到 2.x 迁移窗口再处理。

---

### Migration Notice

The upcoming 2.x series will include large-scale restructuring, architecture adjustments, and Adapter interface updates. According to Semantic Versioning, Manifest changes are considered breaking changes.

For this reason, we will not provide an automatic migration path from 1.x to 2.x. Such migration would be difficult to guarantee across user data, runtime environments, and plugin compatibility, so it would not be a safe or responsible choice.

Instead, v1.6.0 provides an early backup and export path. Users can long-press plugin or environment cards, open the secondary menu, and share or export packages in advance.

We hope this gives users and developers enough time to prepare for Rootless Store 2.0, which will arrive later with a more integrated and more powerful experience.

### 迁移说明

即将到来的 2.x 系列会进行大规模调整，包括工程结构、整体架构以及 Adapter 接口更新。根据语义化版本规范，Manifest 变更属于 Breaking Change。

因此，我们不会提供从 1.x 到 2.x 的自动迁移方案。这类迁移很难同时保证用户数据、运行环境和插件兼容性，并不是一个安全、负责的选择。

作为替代，v1.6.0 提前提供了备份与导出入口。用户可以长按插件或环境包卡片，打开二级菜单，提前分享或导出相关包。

我们希望这能让用户和开发者有更充足的时间准备迁移，并更从容地等待 Rootless Store 2.0 带来更加一体化、更具冲击力的新体验。
