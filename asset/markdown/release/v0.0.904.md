# 全局执行上下文切换版

Welcome to Rootless Store v0.0.904!

This update focuses on execution context control. In v0.0.904, Rootless Store adds a global context switcher on the Home screen and lets plugin execution follow the selected context more consistently.

欢迎来到 Rootless Store v0.0.904！

这个版本的重点放在执行上下文控制上。v0.0.904 在首页加入了全局上下文切换入口，并让插件执行更稳定地跟随当前所选上下文。

---

### What's New in v0.0.904

* **Global Context Switcher**:
    * Added a global execute context switcher from the Home screen.
    * Users can choose between available contexts such as LIMITED, ADB, and ROOT.
* **Execution Context Persistence**:
    * The selected context can now be remembered and reused.
* **Execution Flow Alignment**:
    * Plugin execution now follows the selected global context more consistently.

### v0.0.904 更新内容

* **全局上下文切换器**:
    * 在 Home 页面新增了全局执行上下文切换入口。
    * 用户现在可以在 LIMITED、ADB、ROOT 等可用上下文之间进行选择。
* **上下文记忆**:
    * 当前选择的执行上下文现在可以被保存并复用。
* **执行流程统一**:
    * 插件执行现在会更一致地跟随当前选中的全局上下文。

### 已知问题与未来计划
