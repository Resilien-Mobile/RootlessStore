# 远端插件图标支持版

Welcome to Rootless Store v1.3.1!

This release continues improving plugin personalization. In v1.3.1, Rootless Store adds support for remote plugin icon loading, allowing plugin icons to be loaded directly from full HTTP / HTTPS URIs instead of only relying on local packaged icon paths.

欢迎来到 Rootless Store v1.3.1！

这个版本继续完善插件个性化展示能力。v1.3.1 新增了远端插件图标加载支持，让插件图标可以直接通过完整的 HTTP / HTTPS URI 获取，而不再只能依赖本地插件包内的图标路径。

---

### What's New in v1.3.1

* **Remote Plugin Icon Loading**:
    * Added support for loading plugin icons from remote HTTP / HTTPS URIs.
    * Plugin developers can now provide full icon URIs in plugin metadata.
* **Better Icon URI Compatibility**:
    * Remote icon URIs are now preserved instead of being incorrectly resolved as local file paths.
    * Local icon paths are still resolved against the plugin package directory as before.
* **Image Loading Improvements**:
    * Added Coil Ktor network support for remote image requests.
    * Remote icon loading now reuses the app's shared Ktor client.
* **Icon Display Polish**:
    * Adjusted dynamic plugin icon spacing for a cleaner display in the plugin list.

### v1.3.1 更新内容

* **远端插件图标加载**:
    * 新增了从远端 HTTP / HTTPS URI 加载插件图标的能力。
    * 插件开发者现在可以在插件元信息中直接提供完整图标 URI。
* **更好的图标 URI 兼容性**:
    * 远端图标 URI 现在会被保留，不会再被错误地当作本地文件路径处理。
    * 本地图标路径仍会按原有方式基于插件包目录进行解析。
* **图片加载能力优化**:
    * 新增了 Coil Ktor 网络加载支持，用于处理远端图片请求。
    * 远端图标加载现在会复用应用内已有的 Ktor 客户端。
* **图标展示细节优化**:
    * 调整了动态插件图标的显示间距，让插件列表中的图标展示更自然。

---

### Known Issues & Future Plans

* Remote icon loading depends on network availability and remote resource accessibility.
* If a remote icon fails to load, Rootless Store will continue falling back to the default plugin icon.

### 已知问题与未来计划

* 远端图标加载依赖网络状态和远端资源可访问性。
* 如果远端图标加载失败，Rootless Store 仍会回退到默认插件图标。
