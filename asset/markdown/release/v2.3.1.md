# Rootless Store v2.3.1 发布：只要有想法，人人都可以是开发者

Welcome to Rootless Store v2.3.1!

This release makes it easier to turn personal ideas into reusable actions.

The release now includes a visible test matrix, helping users understand the verified scope before installing or updating. Code Brick also becomes easier to share and convert, while the second round of i18n localization brings a more consistent experience across the app.

欢迎来到 Rootless Store v2.3.1！

这次更新让“有想法”到“可复用”之间的距离更短。

Release 现在会展示更加清晰的测试矩阵，帮助用户在安装或更新前了解当前版本的验证范围。同时，Code Brick 的分享与插件转换体验得到完善，第二轮 i18n 本地化也让应用各处的文字和操作更加统一。

---

### What's New in v2.3.1

* **Clearer Release Test Matrix**:
    * Release pages now include a visible test result summary.
    * Users can understand which checks passed, failed, or were skipped.
    * This makes it easier to judge the current release before installing or updating.

* **Code Brick Sharing**:
    * Long-press a Code Brick card to enter the sharing preview.
    * Share custom Tokens with other users, making it easier to pass along and reuse your ideas.
    * Personal actions now have a simpler path from creation to sharing.

* **More Flexible Plugin Conversion**:
    * When converting a Code Brick into a plugin, users can choose whether it runs once or stays active.
    * This makes the generated plugin better suited to different usage needs.

* **Second Round of i18n Localization**:
    * More visible text and actions now provide a consistent localized experience.
    * Environment switching, plugin management, Shell, settings, and Code Brick pages have been further unified.
    * Dialogs, empty states, buttons, and operation prompts are easier to understand across supported languages.

### v2.3.1 更新内容

* **更加清晰的 Release 测试矩阵**:
    * Release 页面现在会展示测试结果摘要。
    * 用户可以了解哪些检查已经通过、失败或被跳过。
    * 在安装或更新前，用户可以更容易判断当前版本的验证范围。

* **Code Brick 分享支持**:
    * 现在可以长按 Code Brick 卡片进入分享预览。
    * 可以将自定义 Token 分享给其他用户，让自己的想法更容易被传递和复用。
    * 从创建自定义操作到分享给他人，现在拥有了更加直接的路径。

* **更加灵活的插件转换**:
    * 将 Code Brick 转换为插件时，现在可以选择一次性运行或持续运行。
    * 生成的插件能够更贴合不同的使用需求。

* **第二轮 i18n 本地化**:
    * 更多可见文字和操作现在拥有更加统一的本地化体验。
    * 执行环境切换、插件管理、Shell、设置和 Code Brick 页面进行了进一步统一。
    * 弹窗、空状态、按钮和操作提示在支持的语言下更加容易理解。
