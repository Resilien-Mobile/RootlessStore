# Rootless Store v2.3.1 发布：让每次发布更有依据

Welcome to Rootless Store v2.3.1!

This is a small, release-focused update. It does not introduce major new features, but improves how each version is tested, prepared, and presented before release.

Starting with this version, release notes will include test matrix information, making it easier to understand which devices, environments, and usage scenarios have been verified.

欢迎来到 Rootless Store v2.3.1！

这是一次以发布流程为主的小版本更新，没有加入大量新功能，而是重点调整了版本发布前的测试与整理流程。

从这个版本开始，Release 中会逐步加入测试矩阵信息，让用户能够更直观地了解当前版本已经验证了哪些设备、环境和使用场景。

---

### What's New in v2.3.1

* **Release Test Matrix**:
    * Added the initial release test matrix.
    * Users can more clearly understand which scenarios have been verified.
    * Future releases will continue to expand and improve the test coverage.

* **Release Process Improvements**:
    * Refined the preparation and validation process before release.
    * Made version updates more consistent and easier to review.
    * This provides a more reliable foundation for future updates.

### v2.3.1 更新内容

* **加入 Release 测试矩阵**:
    * 新增初步的版本测试矩阵。
    * 用户可以更清楚地了解当前版本已经验证了哪些使用场景。
    * 后续版本会继续扩展和完善测试覆盖范围。

* **发布流程调整**:
    * 优化了版本发布前的准备与检查流程。
    * 让每次版本更新更加统一，也更容易进行确认。
    * 为后续持续发布提供更加可靠的基础。

---

感谢大家持续关注和测试 Rootless Store。每一次测试结果和反馈，都会帮助后续版本变得更加透明、可靠。
